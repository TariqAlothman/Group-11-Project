# CookSmart - Group 11 Project

Group 11 Final Project for SWE363 Term 252 KFUPM Course. This repository contains the front-end prototype for CookSmart, demonstrating key user flows, interactions, and a fully functional Admin Dashboard.

## 🚀 Setup & Installation

Follow these steps to set up the project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TariqAlothman/Group-11-Project.git
   cd Group-11-Project/frontend
   ```

2. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **View the Application:**
   Open [http://localhost:5173](http://localhost:5173) (or the port specified in your terminal) in your browser.

## 📂 Project Structure
- `src/components/`: Reusable UI components (like the Navbar and standard Buttons).
- `src/pages/`: Main views for the application, featuring dedicated subfolders for `/admin` and `/user` routes.
- `src/styles/`: Global stylesheets and module css.
- `src/assets/`: Images and vector icons utilized in the design.

## 🛠 Features Developed
- Fully interactive Admin Dashboard
- Review Queue with mock data and real-time state management
- Searchable and filterable Manage Users page
- Interactive Manage Categories interface
- Fully responsive design on both mobile and desktop environments
